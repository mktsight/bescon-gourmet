# 導出ルール（最小入力 → 仕様 JSON）

ユーザーから聞くのは 編名・開催日・集合時刻・集合場所・運動内容・ご褒美の食事 の6つだけ。残りはこのルールで決め、仕様の `_derived` に根拠を残し、報告でユーザーに示す。

## 曜日（手で書かない）

曜日・日時行・ヘッダーの `SAT` などは**ジェネレーターが `date` から計算する**。思い込みで曜日を書かない。`overview.date.value` は原則省略する（手書きして曜日が違うとビルドがエラーになる）。描画後の出力 `曜日: 土（SAT）` と PNG で確認する。

## エリアのローマ字（area_romaji）

- ヘボン式・大文字。長音は省略（とうきょう → TOKYO、おう → O）。
- 「駅前」「温泉」などの一般語は英語にしてよい: 駅前 → STATION（例 `YAMAGATA STATION`）。温泉は `ONSEN` でもよい（例 `ZAO ONSEN`）。
- 24文字以内、使える文字は大文字英数字・空白・`.` `'` `&` `-`。
- 前例: 山寺 → `YAMADERA`、蔵王ライザ → `ZAO`、上山 → `KAMINOYAMA`、山形駅前 → `YAMAGATA STATION`、天童 → `TENDO`。

## キャッチコピー（subtitle）

- 型: 「{場所}の{対象}を{動詞て形}、整った体で{ご褒美}と乾杯」
- 運動で整える → ご褒美、の流れが一目で分かること。全角26文字以内を目安（幅 779 を超えると縮小される）。
- 温泉が入る回は「ととのえた体」も可。
- 前例:
  - 山寺: 山寺の石段を登って、整った体で板そばと乾杯
  - 蔵王ライザ: 蔵王の高原を歩いて、整った体で石窯ピザと乾杯
  - 上山: 温泉街を歩いて、ととのえた体でワインと乾杯
  - 山形駅前: 公園を歩いて、整った体で山形牛と乾杯

## 消費カロリー（kcal_basis）

`kcal_basis: {mets, hours, activity}` を書くと、ジェネレーターが次の式で計算する。

```
kcal = round(METs × 60kg × 時間h × 1.05 ÷ 50) × 50
```

METs 表:

| 運動 | METs |
|---|---|
| ウォーキング（平地・ゆっくり） | 3.5 |
| 坂道・速歩 | 4.3 |
| サイクリング（ゆっくり） | 4.0 |
| ウォーク／ジョグ混合 | 5.0 |
| ハイキング | 6.0 |
| ジョギング | 7.0 |
| 雪上ハイク・スノーシュー | 7.0 |
| 登山・石段 | 8.0 |

- 時間 hours = 当日の流れの「運動開始」から「到達・記念撮影の後、店へ移動するまで」のうち実際に体を動かす時間（休憩・撮影の長い時間は引く）。前例は 1.2〜1.5 時間。
- 前例:

| 編 | activity | METs × 時間 | 計算値 | kcal |
|---|---|---|---|---|
| 山寺 | 石段登山 | 8.0 × 1.2 | 604.8 | 600 |
| 蔵王ライザ | 高原ハイク | 6.0 × 1.5 | 567 | 550 |
| 上山 | 城下町ウォーク | 3.5 × 1.5 | 330.75 | 350 |
| 山形駅前 | ウォーク／ジョグ | 5.0 × 1.25 | 393.75 | 400 |

- ユーザーには必ず「〇 METs × 〇時間 → 約 〇 kcal（体重60kg換算）」と根拠を示す。ユーザーが数値を指定したら `kcal` に直接書く（kcal_basis より優先）。

## 持ち物（overview.items）

運動の種類ごとの基本:

| 運動 | 持ち物 |
|---|---|
| 登山・石段 | 滑りにくい靴・動ける服装・飲み物・防寒着 |
| 高原ハイク・ハイキング | 防寒着・歩きやすい靴・手袋・飲み物 |
| ウォーク・ジョグ | 歩きやすい靴・動ける服装・飲み物 |

- 温泉に入る流れなら「（希望者は）入浴セット」を足す。
- 12月〜3月は「防寒着」「手袋」を必ず入れ、靴は「雪道で滑りにくい靴」にする。
- 「・」区切りで1行（幅を超えると縮小される。長すぎるときは重要度の低いものから削る）。

## 当日の流れ（timeline）

集合時刻 S から5ステップを組むのが基本（4〜6個まで可、最後が必ずご褒美）。

| ステップ | 時刻 | ラベルの型 |
|---|---|---|
| 1 | S | {集合場所}に集合・\|準備運動 |
| 2 | S + 15分 | {運動}を各自の\|ペースで〜 |
| 3 | S + 約1時間30分 | {到達点}で\|記念撮影 |
| 4 | S + 約2時間15分 | {店}へ\|移動 |
| 5 | S + 約2時間30分 | {ご褒美}で乾杯・\|次回ゴール相談 |

- 前例（山寺）: 9:30 / 9:45 / 11:00 / 11:45 / 12:00。
- ラベルは2行、各行は全角9文字以内を目安に `|` で分ける（`|` が無いと自動で折り返す）。
- 温泉を挟む回は「日帰り温泉で|ととのえる」を4番目に入れる（上山の前例）。
- 運動時間（kcal の hours）と矛盾しないようにする。

## 開催概要の各行

- 集合（place）: 集合場所。note に最寄り駅やアクセス（例「※JR奥羽本線でアクセス」）。
- 運動（exercise）: 何をどこで、が分かる1行（例「舞鶴山（天童公園）の雪道ハイキング」）。
- 食事（meal）: 「〇〇後、{店}で{料理}＆乾杯」の型。
- 持ち物（items）: 上のルール。

## 注記（notes）と caution

- 1行目: 予約の案内。例「※9名・土曜昼は混雑のため店は事前予約。」（メンバーは9名）
- 2行目: 代替案やアドバイス、そして**営業時間・定休日は要確認**。全角空白 `　` で始める。例「　店の営業時間・定休日は事前に必ず確認を。」
- caution: 冬（12月〜3月）、山、天候リスクのある回は `true`（赤い ⚠ 表示）。前例では蔵王（11月の高原）が true。

## お店の確認

- ご褒美の店・料理は Web 検索で実在・場所・提供内容を確かめる。
- 確認できたことだけを書き、営業時間・定休日は必ず「要確認」とする（季節営業・冬季休業に注意）。
- 見つからない場合は推測で店名を作らず、ユーザーにその旨を伝え、注記にも要確認と書く。
